
# 🚀 Project 1 : API Automation & CI/CD — Restful Booker

Ce projet vise à automatiser la suite de tests fonctionnels et de régression pour l'API **Restful Booker**.

## 🛠️ Stack Technique
- **API Cible :** Restful Booker
- **Conception des tests :** Postman
- **Exécution CLI :** Newman
- **CI/CD :** GitHub Actions

## 📋 Scénarios de tests couverts
- [ ] **Auth :** Génération du jeton d'authentification (Token)
- [ ] **Booking :** Création, lecture, mise à jour et suppression de réservations (CRUD)
- [ ] **Assertions :** Validation des codes HTTP, du schéma JSON et des temps de réponse
